# Updating

Run the newer setup on the bay PC. It closes BayLauncher if it is running, replaces the program, and keeps your cards,
pictures, look, screens and staff PIN (they live in `C:\ProgramData\BayLauncher`). Then sign out and back in, or
start Start > BayLauncher > BayLauncher in a window to check it.
